# Code of Conduct

We want this project to be useful, careful, and welcoming.

## Expected Behavior

- Be respectful and constructive.
- Keep discussions focused on reproducible behavior, data policy, and project goals.
- Avoid uploading or requesting raw game data in issues, pull requests, or discussions.
- Give maintainers and contributors room to ask clarifying questions.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private contact information without permission.
- Repeatedly ignoring the repository data policy after maintainers have clarified it.

## Enforcement

Maintainers may edit, hide, or remove comments and may restrict participation when needed
to protect contributors or the project.

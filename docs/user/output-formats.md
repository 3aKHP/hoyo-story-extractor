# 产出格式说明

所有提取产出的 `.txt` 文件使用 UTF-8 编码，Markdown 风格格式。

---

## Quests（任务剧情）

每个 quest 一个文件。格式：

```markdown
# 任务标题
*任务描述*
> 第一章 第X幕

### 子任务标题

**说话人**：台词内容

**说话人**：台词内容

### 另一个子任务

**说话人**：更多台词
```

**字段说明**：

| 元素 | 格式 | 来源 |
|------|------|------|
| 任务标题 | `# 标题` | `ChapterTitle` 字段 |
| 任务描述 | `*描述*` | `MainQuestDesp` 字段 |
| 章节号 | `> 第X章 第Y幕` | `ChapterNum` 字段 |
| 子任务 | `### 子任务标题` | `SubQuestTitle` 字段 |
| 对话 | `**角色名**：台词` | Speaker + Dialog |
| 舞台指示 | 不带 `**` 前缀的纯文本 | 空 Speaker 的 Dialog |

**命名规则**：`{序号4位}_{任务标题}.txt`

## Talks（NPC/物件对话）

按 Talk 类型分目录，每个 talk 一个文件。格式：

```markdown
# {Type} Talk {talkId}

**角色名**：对话内容

**角色名**：下一句对话
```

**Talk 类型目录**：

## Avatars（角色资料）

每个角色一个文件。格式：

```markdown
# 角色名

角色描述文本

- **神之眼**: 元素类型
- **命之座**: 命之座名称
- **生日**: MM.DD
- **称号**: 称号文本

## 语音

**初次见面…**：台词

**闲聊·独白**：台词

## 角色故事

### 角色详细

故事内容…

### 角色故事1

故事内容…
```

## Misc（物品/武器/圣遗物）

### Materials

```markdown
# 材料名称

材料描述文本
```

### Weapons

```markdown
# 武器名称

武器描述

## 技能

**技能名称**
技能描述（Lv1-5 完整）

## 背景故事

武器的背景故事文本
```

### Relics

```markdown
# 圣遗物名称

圣遗物描述

## 背景故事

圣遗物的背景故事文本
```

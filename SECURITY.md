# Security Policy

## Supported Versions

Only the latest released version is supported for security fixes.

## Reporting a Vulnerability

Please do not open a public issue for security-sensitive reports.

Send a report to the maintainer email listed in `pyproject.toml` with:

- affected version or commit
- reproduction steps
- expected impact
- any relevant logs or proof of concept

We will acknowledge valid reports as quickly as possible and coordinate a fix before
public disclosure when appropriate.
